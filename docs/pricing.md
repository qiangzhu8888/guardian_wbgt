# WBGT 監視プラットフォーム — 料金表（叩き台）

> **用途**: 社内・顧客提示用のたたき台です。金額は **例示（税別）** です。正式採用前に原価・粗利・法務レビューで調整してください。  
> **前提**: クラウドは主に **Firebase（従量）**、セルラーは **1NCE 等の IoT SIM** を想定。Firebase の実コストは利用パターンで変動します。**ハードの標準構成は BUILDICS® L5（温湿度センサー付き）1 台（39,800 円/台・税別）／拠点**を想定し、下表に反映しています。

### 導入しやすさの方針（例示）

- **月額の上限を抑える**: まずは **Lite** で 1 拠点から試し、拡大時にプランアップ。  
- **現地費用は要見積のまま**: 距離・骨組み・電源次第のため見積分離。**遠隔セットアップ中心**にすれば初期は **L5 本体＋低めの遠隔費**に抑えやすい。  
- **SIM はバンドル表示も可**: 端末・通信を **ワンパッケージ**で提示すると意思決定が早い（実コストは仕入れに合わせて調整）。

## 6. 夏季のみ・シーズンで利用する場合

暑さ対策として **6〜9 月だけ** など **決まった期間だけ** 使いたい場合の進め方の例です（契約条項・金額は個別に調整）。

### 6.1 おすすめの契約の形


| パターン             | 内容                                                                                          | 向いている場合                        |
| ---------------- | ------------------------------------------------------------------------------------------- | ------------------------------ |
| **シーズン契約（期間固定）** | 例: **5 月〜9 月**を「利用期間」とし、その期間だけ **Lite 等の月額**を請求。期間外は **利用休止**（ダッシュボード閲覧・データ受信の扱いを契約で定義）     | 毎年同じ現場で繰り返す工事・イベント・校庭など        |
| **夏季パック（前払い）**   | 例: **5 ヶ月分の月額を一括**＋ **◯％オフ**（いったん前受として計上し、途中解約は返金なし等を明記）                                    | 予算が「夏の防災・安全費用」にまとまっている場合       |
| **オフシーズン維持料**    | 冬季は **閲覧のみ** or **完全スリープ**し、**月額 500〜1,000 円（例）** だけテナント・SIM 割当を維持。翌年は **再開手数料なし or 一律 ◯円** | 端末を現場に置いたまま／翌年も同じ運用を簡単に再開したい場合 |


### 6.2 運用上の注意

- **端末（L5）**: オフシーズンは **撤去して倉庫保管**し、翌年再設置でもよい。**1NCE 等の SIM** は長期プランでもデータ総量に上限があるため、**非稼働中は送信停止・電源オフ**で無駄な通信を抑える。  
- **クラウド**: Firebase は完全ゼロ円にはなりにくいため、**「休止中の最低料金」または前払パックに含める**か、契約で明記する。  
- **再開時**: 遠隔で **閾値・組織・Wi-Fi／APN** を再確認できるように **再開チェックリスト**（社内向け）を用意するとスムーズ。

### 6.3 料金の例（税別・叩き台）


| 内容                             | 例示                                                    |
| ------------------------------ | ----------------------------------------------------- |
| 夏季 **5 ヶ月**のクラウド（Lite 相当を単純按分） | 2,980 円 × 5 ＝ **14,900 円**（パック割で **12,000 円前後**にする余地） |
| オフシーズン **7 ヶ月**の維持             | **500〜1,000 円/月** × 7 をパックに含める or 実費                  |


※いずれも **L5 本体・遠隔・現地は別**。「夏季だけ」を訴求するなら **夏季パック総額**（端末＋5 ヶ月クラウド＋再開支援）の **一式見積**が顧客には伝わりやすいです。

## 7. 「売切のみ」パターン（参考）

Firebase は従量のため、**完全売切のみ**はベンダリスクが残ります。どうしても売切に近づける場合の例:


| 型                  | 内容                                       |
| ------------------ | ---------------------------------------- |
| **2 年ライセンス前払い**    | 月額 × 24 に **一括値引 5〜10%**（超過条項は必須）        |
| **端末売切＋初年度クラウド同梱** | 2 年目以降は月額へ移行                             |
| **初年度 Lite 無料・割引** | 単年契約＋自動更新など条件付きで **導入ハードルを下げる**（原価と必ず突合） |
